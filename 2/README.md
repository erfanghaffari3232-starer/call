# Erfan Video — پوشه 2

این صفحه تماس تصویری دونفره است. هر دو نفر باید یک اسم اتاق یکسان وارد کنند و دکمه شروع را بزنند. سایت باید روی HTTPS اجرا شود و مرورگر اجازه دوربین و میکروفون داشته باشد.

## اجرا
- مخزن GitHub Pages را فعال کنید و مسیر `/2/` را باز کنید.
- هر دو نفر یک نام مشترک مانند `erfan-123` وارد کنند.

## نکته فنی
این نسخه از PeerJS عمومی برای سیگنال‌دهی استفاده می‌کند و تماس را با WebRTC برقرار می‌کند. در شبکه‌هایی که PeerJS یا WebRTC را مسدود می‌کنند، اتصال ممکن است انجام نشود؛ برای پایداری بیشتر معمولاً سرور TURN لازم است. تماس واقعی بین دو دستگاه در این تغییر آزمایش نشده است.
