# Erfan Voice — تماس صوتی واقعی با WebRTC

این پروژه یک تماس صوتی دونفره در مرورگر است که از WebRTC و PeerJS برای سیگنال‌دهی استفاده می‌کند. فایل‌ها ایستا هستند و برای اجرای صفحه می‌توان از GitHub Pages استفاده کرد.

## انتشار روی GitHub Pages
1. در GitHub یک مخزن عمومی بساز به نام `erfan-voice`.
2. فایل‌های `index.html`، `style.css` و `app.js` را در ریشه مخزن آپلود کن.
3. به **Settings → Pages** برو.
4. در بخش Build and deployment گزینه **Deploy from a branch** را انتخاب کن، سپس `main` و `/(root)` را ذخیره کن.
5. آدرس GitHub Pages را باز کن. میکروفون به HTTPS نیاز دارد؛ GitHub Pages از HTTPS پشتیبانی می‌کند.

## برقراری تماس
1. هر دو نفر آدرس وب‌سایت را باز کنند.
2. نفر اول روی «روشن‌کردن میکروفون» بزند و اجازه میکروفون بدهد.
3. نفر اول «شناسه تماس تو» را کپی و برای نفر دوم ارسال کند.
4. نفر دوم صفحه را باز کند، میکروفون را روشن کند، شناسه نفر اول را در کادر وارد کند و دکمه «تماس با شناسه» را بزند.
5. اگر نفر اول تماس ورودی را ببیند، تماس خودکار پاسخ داده می‌شود. صفحه را تا پایان تماس باز نگه دارید.

## نکات مهم
- به اینترنت نیاز دارد و سرویس عمومی PeerJS برای سیگنال‌دهی استفاده می‌شود؛ این پروژه سرور اختصاصی ندارد.
- WebRTC معمولاً صدای واقعی را مستقیم بین دستگاه‌ها می‌فرستد، اما بعضی شبکه‌ها/فایروال‌ها ممکن است اتصال مستقیم را مسدود کنند. برای پایداری بالاتر در چنین شبکه‌هایی، سرور TURN لازم است.
- شناسه تماس را فقط با شخصی که می‌خواهی تماس بگیری به اشتراک بگذار.
- این بسته را در این گفتگو آماده کرده‌ام؛ هنوز به حساب GitHub تو پوش نکرده‌ام.
